# 天眼 / GodEye 实现契约

目标：完成 prd.md 的七级视觉能力，运行于网易中国版基岩版 Python ModSDK，支持手机、单机与本地联机。现有 manifest.json / format_version 2 与 UUID 保留；最低引擎声明 1.18.0。本机安装了 3.10.0.420447 开发包，具体运行验证另行记录。

## 功能

- UI 悬浮入口、七级选择、说明、当前等级、关闭设置页；选择等级、分类开关或范围即自动保存生效，Lv.0 关闭能力；无物品、配方或资源消耗。
- 右侧选项复用能力规则判断资格，不适用时显示灰色「关」且禁用触控，回调另有资格守卫；范围显示「未启用」。显示状态由资格和偏好共同决定，等级不足时能力和显示状态均为关闭。降低等级保留偏好，恢复等级后可继续操作。禁用时 default/hover/pressed 三态均复用已有 button.png，通过 JSON grayscale / SetSpriteGray 原生置灰，不依赖新增灰色贴图或叠层；可用时恢复原色并区分开启和关闭底色。
- 悬浮入口默认右上角，按下/移动/抬起/取消事件区分轻点与拖动；以 UI 坐标限制屏幕边界，归一化位置随本次客户端会话保留。`>天眼归位` 经服务端聊天事件只通知发送者，切换入口显隐，显示时重置位置。
- Lv.0 关闭；Lv.1 客户端微光；Lv.2 原生持续夜视；Lv.3 夜视与暗处色彩增强；Lv.4 特殊生命和稀有矿脉粗略提示；Lv.5 隐藏目标和矿脉定位；Lv.6 综合能力和空间标记。
- 原生夜视 amplifier 不作为亮度分级。微光/增强使用客户端后处理，提供可关闭的视觉增强选项。
- 服务端保存玩家设置，进入、复活、维度完成事件后重建状态；客户端主动握手补偿加载时序。
- 探测限已加载区域。原版和深层矿石、可配置矿石、矿脉合并、方向/距离/已发现数量。
- 特殊实体：白名单、公开实体标签、隐身状态。方块：矿石、容器、机关白名单。秘密入口、房间与任务目标通过服务端注册协议接入，不推断其他模组私有变量。
- Lv.4 不发送矿石精确位置、类型或数量，服务端生成粗略方位与距离；Lv.5 定位，Lv.6 空间标记。
- 同名夜视效果共存采用外部效果记录与保守撤销策略，无法保证与主动覆写同名效果的模组零冲突，明确记录残留策略。

## 实现结构与所有权

- `behavior_pack_qbUAm8gp/godEyeScripts/modMain.py`：注册双端系统。
- `config.py`：唯一命名空间 `mercuryx_godeye`、等级、目标目录、性能参数。
- `core.py`：纯 Python 设置归一化、空间分块、缓存调度、矿脉聚合、方位、目标注册。
- `server_system.py`：持久化、效果、世界查询、玩家独立结果、注册协议。
- `client_system.py`：握手、视觉、HUD、设置申请、空间标记。
- `ui.py` 和资源包 `ui/`：触屏界面、信息卡片。
- `tests/`：算法与模拟引擎集成测试；测试代码不进入发布包。
- `tools/`：构建、静态检查和复现测试工具。

消息链：UI 申请 -> 服务端归一化/保存 -> 带修订号的状态 -> 扫描 -> 同一玩家结果 -> 客户端绘制。切换维度或设置时递增修订号；旧结果丢弃。

点击直接发起设置申请，同一时间只保留一个在途请求和一个最新完整设置。收到回包后至少间隔 6 tick 再提交连续操作，沿用服务端限频；后续点击和关闭/重开界面不丢失最新选择。菜单选中态跟随最新选择，「当前」等级跟随服务端确认，保存中显示提示。初始化未同步时禁止修改；保存失败或 150 tick 超时清空待提交状态并恢复已确认设置，允许再次点击重试。

持久化结构：`schema_version`、`level`、`ore_enabled`、`entity_enabled`、`hidden_enabled`、`enhancement_enabled`、`performance`。实际能力根据 level 和偏好计算；不持久化扫描结果或实体对象。

## 性能与兼容

实体查询与方块查询分开调度。方块按 8×8×8 单元分批处理；同维度玩家共享有界缓存。只保留感兴趣区域，缓存超时/方块变化后重扫。近处优先，玩家轮转，限制单次工作量和总时长。HUD 标记数量有上限；停止、离线、维度切换清理任务。

不覆盖原版实体、方块材质、HUD JSON 或已有世界方块。目标注册支持类别、维度、位置、可见玩家、失效与注销。不会加载远方区块。
