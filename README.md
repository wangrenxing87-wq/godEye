# 天眼 / GodEye

网易《我的世界》中国版基岩版视觉能力组件。玩家通过界面选择七级能力，无需物品、药水或资源消耗。使用 Python ModSDK，不适用于 Java Forge/Fabric 或国际版 Script API。

## 使用

1. 将 `dist/MercuryX_GodEye_1.0.0.mcaddon` 导入 MC Studio，类型选择「基岩版 / 附加包」，在工程中启用 Python 脚本（`CodeEnable=true`），同时加载行为包和资源包。也可直接使用本工作区工程，其脚本开关已启用。仅导入压缩包时，Studio 不会自动开启脚本。
2. 进入世界，轻点右上角的眼睛图标「天眼」打开设置；按住按钮可拖动到屏幕内任意位置，拖动松手不会打开设置。电脑版也可在游戏视角下按 **G**，或在聊天中输入 `!godeye` / `天眼`。
3. 点击等级、分类开关或范围档位即自动生效并保存，无需确认。选择 **Lv.0 凡人** 关闭能力。等级和分类开关随该玩家的世界存档保存。
4. 初次探测需要分批加载结果。界面会显示探测进度；未探测区域不表示没有目标。

在聊天中输入 `>天眼归位` 可切换悬浮按钮的隐藏/显示：显示时输入会隐藏，再次输入会显示并移回右上角。只影响自己的按钮，不关闭天眼能力。按钮位置和显隐状态在本次游戏中保留（包括切换维度），重新进入世界恢复默认显示于右上角。

Windows 开发包用鼠标操作悬浮按钮时，先按 **F11** 进入触控模拟，再按住按钮拖动；手机直接用手指拖动即可。更新组件后需重新进入世界加载新的 UI 资源。

| 等级 | 能力 |
|---|---|
| Lv.0 凡人 | 关闭天眼效果和扫描 |
| Lv.1 微光 | 暗处轻度画面提亮 |
| Lv.2 夜瞳 | 原生夜视自动续期 |
| Lv.3 幽视 | 夜视加暗处色彩增强 |
| Lv.4 灵视 | 特殊生命、隐形生物、稀有矿脉的大致方向和距离 |
| Lv.5 天眼 | 矿脉定位、容器、机关及已接入的隐藏或任务目标 |
| Lv.6 真·夜瞳 | 全部能力，加可穿遮挡的世界文字标记 |

「矿脉感知」「特殊生命」「隐藏目标」「画面增强」可分别关闭。当前选择的等级不支持的开关统一显示灰色「关」，对应能力不生效，无法点击开启；范围不可用时显示「未启用」。切回适用等级后恢复，并保留之前的开关偏好。可用且已开启的开关使用青色背景，可用但已关闭的开关使用深色背景，等级不足时使用灰色背景。矿脉感知、特殊生命及范围从 Lv.4 可用，隐藏目标从 Lv.5 可用；画面增强仅 Lv.1、Lv.3～6 可用，Lv.2 使用原生夜视。

省电、均衡、高范围对应最大探测半径 16、24、32 格；Lv.4 矿脉半径最多 16 格。连续快速点击时按最后选择自动保存，关闭设置页也会继续完成保存。底部会显示保存状态；保存失败或连接超时会提示，并恢复到已确认的设置。

## 兼容边界

- 只查询已加载区块，不加载远方地图。不会修改世界方块或替换原版材质。
- 普通箱子显示为箱子，不推断其是否属于秘密任务。秘密入口和其他模组私有任务逻辑需要接入公开协议，见 [接入文档](docs/integration-api.md)。
- 矿脉按同类矿石六面相邻合并。「已探测 N 块」表示当前已加载扫描范围中的数量，不承诺完整矿脉规模。
- 微光和增强使用客户端色彩后处理；原版夜视的 amplifier 不产生更亮的等级。纯黑细节、其他包的特殊黑暗效果不保证可恢复。已有色彩滤镜启用时，天眼保留它并提示。
- 关闭天眼保留已知的外部夜视。多个模组同时覆写原版同名效果或同一后处理通道时，无法保证完全隔离。
- 当前实测环境为 Windows 开发包 **3.10.0.420447**。最低引擎声明保留 **1.18.0**，不表示已验证所有旧引擎。手机触控、手机性能和真实多人结果见 [验收记录](docs/acceptance.md)。

## 源码与构建

运行时源码在 `behavior_pack_qbUAm8gp/godEyeScripts/`；JSON UI 和纹理在 `resource_pack_F1LzIf84/`。两包及模块 UUID 因导入冲突于 2026-10-01 重新生成，映射见 [UUID记录](release/package/uuid-regeneration.json)。内部命名空间为 `mercuryx_godeye`。

```powershell
# 实际 ModSDK 的 Python 2.7 兼容测试
python -m unittest discover -s tests
# 工具使用 Python 3
py -3 -X utf8 -m unittest discover -s tests
py -3 tools/generate_resources.py
py -3 tools/build.py
```

构建产物为 `dist/MercuryX_GodEye_1.0.0.mcaddon`，旁边的 `.sha256.json` 记录包及每个文件的校验值。包内仅含行为包和资源包；测试工具、开发探针及工作区账号配置不参与导出。
