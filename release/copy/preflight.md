## 命名空间与正式导出

发布技能的既定契约要求自定义命名空间为`mercuryx`。当前工程系统名为`mercuryx_godeye`；本地正式导出命令因此未成功。详情见`../package/inspection-report.json`及`../package/export-report.json`。

需要在后续版本迁移时成套处理以下关系，并完成存档兼容验证：

| 内容 | 当前值 | 迁移时的要求 |
|---|---|---|
| System/事件/UI注册域 | config.NAMESPACE = mercuryx_godeye | 调整为mercuryx，核对客户端、服务端和接入文档 |
| 玩家等级与偏好 | mercuryx_godeye:settings_v1 | 新键增加godeye前缀避免组件间冲突；旧值按需迁移，不能重置玩家设置 |
| 夜视归属存档 | mercuryx_godeye:night_lease_v1 | 兼容旧归属，避免关闭时删除其他来源的夜视 |
| 实体接入标签 | nightvision:*、mercuryx_godeye:* | 定义新标签与旧标签兼容策略；不把历史接入协议误当成新增实体 |
| JSON UI与纹理路径 | mercuryx_godeye.menu / hud、textures/ui/mercuryx_godeye | 属于UI引用/资源路径，不按冒号命名空间盲目替换 |

本轮制作发布内容和检查现有包，未改动运行时标识符、存档键或接入协议，也没有将本模组旧域加入“外部命名空间”以绕过校验。复核包为`GodEye-1.0.0-review.zip`；2026-10-01按用户报告的冲突重建两包UUID并同步依赖，保留当前功能。未生成可宣称通过命名空间规范的`mod.zip`。

最低引擎字段已精确为[1,18,0]，不需要降级字段。实际开发包为3.10.0.420447，旧引擎兼容仍需独立实测。
