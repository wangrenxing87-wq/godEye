# 天眼：七级视觉与探索感知

作品版本：1.0.0。作者品牌：MercuryX。作品类型：网易中国版基岩版玩法组件 / 附加包。

本文件为通用发布介绍。尚未指定活动，因此不声明官方活动关联、奖励或活动日期；报名字段按实际活动表单补充。

## 一句话介绍

无需道具，七级能力随心切换，让夜视、矿脉感知与目标标记陪你探索世界。

## 玩法与特色

玩家从Lv.0至Lv.6自由选择：关闭、微光、夜视、暗处增强、粗略感知、精确定位与世界文字标记。轻点右上角的天眼按钮打开界面，选择后自动生效并保存，桌面端也支持G键和聊天入口。

天眼把“看得清”与“知道附近有什么”放在同一套等级设置中：低等级保留夜晚氛围，高等级逐步增加矿脉、特殊生命、容器与机关信息。矿脉按同类相邻矿石合并，提供当前探测到的数量；方向和距离随玩家位置更新。Lv.6使用可穿遮挡的文字标记，并非任意实体的发光轮廓。

四类效果可单独控制，16/24/32格三档范围适应不同探索需求。开关资格随等级显示，点击即保存，无需额外确认。悬浮入口可以拖动，聊天输入“>天眼归位”可隐藏或恢复至右上角。

适合夜间探索、地下寻矿，以及需要目标引导的地图玩法。秘密入口和任务目标通过公开接口接入；本组件不自带任务剧情或新增生物。

## 安装与体验步骤

1. 在MC Studio中按“基岩版 / 附加包”导入组件，同时启用行为包与资源包。
2. 在工程中开启Python脚本（CodeEnable=true），进入测试世界。单独导入压缩包不会自动开启脚本。
3. 点击右上角“天眼”，先对比Lv.0、Lv.1、Lv.2、Lv.3的暗处画面，再体验Lv.4、Lv.5的探测信息与Lv.6的文字标记。
4. 等待扫描进度推进；切换分类开关、范围档位，确认结果变化。选择Lv.0即可停止能力与扫描。
